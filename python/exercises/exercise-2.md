# Exercise - 2

## 1. Password Check

Ask the user to enter the password. Keep asking until they enter "python".

Sample
```
Enter password: java
Wrong! Try again.
Enter password: python
Welcome!
```
## 2. Skip One Number

Take a number N. Print numbers from 1 to N, but do not print 5.

Input
```
8
```
Output
```
1
2
3
4
6
7
8
```

## 3. Keep Asking Until "yes"

Ask the user:
```
Do you want to continue?
```
Keep asking until they type yes.

## 4. Countdown

Take a number and print a countdown to 1.

Input
```
5
```
Output
```
5
4
3
2
1
Blast Off!
```
